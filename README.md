# world-robo-boxing

Ultimate Robo Boxing is a small, playable browser game. Choose Ironclad, Volt, or
Nova, then fight a randomly selected rival in the championship ring.

## Play

Open `index.html` in a modern web browser. No installation or server is needed.

- **Jab:** click Jab or press `J`
- **Power punch:** click Power Punch or press `K`
- **Block:** click Block or press `Space`

Reduce your opponent's health to zero to win. Use **Choose another fighter** to
return to character selection.
