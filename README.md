# World Robot Boxing (WRB Championship 3D)

Browser-ready 3D Real Steel World Robot Boxing game built with Three.js, Mixamo animations, 93 WRB robot models, 16 3D arenas, ring-card holder (Naman), and responsive mobile + desktop controls.

## Play Online (Vercel)
This repository is structured as a zero-build static web app (`index.html` + chunked `< 40 MB` `.js` asset packs + `vercel.json`) so it deploys directly on **Vercel** (`Framework Preset: Other`, root directory `.`).

## Controls
- **Desktop:** `WASD` Move · `Q / E` Punch Combo · `Z` Dancing Kick · `F / C` Heavy / Fly Attack · `1 / 2 / 3` WRB Specials · `R` Best Special · `Space` Dodge · `G` Block · `B` Dance Mode · `N` Taunt · `U` Sound ON/OFF · `Tab` Switch Fighter
- **Mobile / Touch:** Automatic responsive on-screen D-Pad + action buttons + Android PWA install support (`Add to Home Screen`).
